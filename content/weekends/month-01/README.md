# Month 1 weekends: Web and HTTP in depth

One task for each weekend of month 1. Each task fits 45 minutes on a computer.
The app gets a weekend editor in Sprint 4. Until then, copy the file you need and write in it.

| Weekend | File | Task |
|---|---|---|
| 1 | [week-1-boss.md](week-1-boss.md) | Boss: write a design doc and a Mermaid diagram |
| 2 | [week-2-adr.md](week-2-adr.md) | Write one ADR (a short note about one decision) for a real decision at work |
| 3 | [week-3-ai-agent-drill.md](week-3-ai-agent-drill.md) | AI-agent drill: you first, then the agent, then review |
| 4 | [week-4-gym.md](week-4-gym.md) | Gym: 5 battles in the app |

How to use a file:

1. Copy the file into your own notes. Do not write in this repo.
2. Set a timer for each step.
3. At the end, paste your work and the coach prompt into a new chat at https://claude.ai/new.
4. After the chat, write 2 sentences from memory about what you learned.
5. Once a month, ask one colleague to read one of your design docs or ADRs.
